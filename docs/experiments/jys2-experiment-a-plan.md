## 목표와 기준점

다음 도로·출구만 안내받는 AV가 목적지 방향 차로를 일찍 확보하고, 주변 차량 때문에 바로 이동할 수 없을 때 가감속으로 공간을 찾아 진출하는지 확인한다. 팀의 1차 목표는 완주율과 충돌률의 합 100%, 최종 목표는 여기에 충돌률 5% 미만을 동시에 만족하는 것이다. 합계가 높아도 충돌 증가를 개선으로 판정하지 않는다.

기존 모델에 상세 안내와 안전게이트를 사용한 46/48 완주, 기존 가중치에서 이를 가린 24/48 완주는 과거 참고값이다. A0는 정리한 관측으로 처음부터 학습하고 고교통 평가를 마친 모델이다. 목표 차로를 보았던 가중치는 물려받지 않는다.

## 0단계 · 학습 전 점검

- 내비는 다음 분기의 큰 도로·출구 방향과 실제 분기까지 거리만 준다. 04·14번에서 램프가 다시 갈라질 때 두 경로가 구별되는지 확인한다. 동일 위치·교통에서 목적지만 바꾸면 내비 이외의 관측은 같아야 한다.
- 목표 차로 방향·목록, 경로 맞춤 5차로 연결성, 선행·두 번째 목표 차로 및 유효 표시, SUMO 추천 차로 입력을 제거한다. 물리적인 차로 존재·끝과 도로의 실선 제약은 유지한다. 관측은 실제 쓰는 값으로 구성하고 47차원 이내로 둔다.
- 안전게이트, 자동 제동·자동 차선변경 보정, 기존 목표 차로 한 칸 접근 가점은 끈다. 정책 원본 명령·적용 명령·실제 이동을 구분한다. 차량 측면 겹침, 뒤차 접근, 빈 옆 차로 세 상황이 기존 센서로 구별되는지 점검한다. 누락이 있으면 기준점 학습 전에 수정하고 전 조건에 동일 적용한다.
- 분기 통과, 목표 차로 확보 시점, 위험한 측면 변경을 진단 로그로 먼저 기록한다. 보상 계수를 0으로 두었을 때 기본 보상이 변하지 않는지, 중복 지급·고가 교차 차량 오인·자연스러운 도로 연결에 의한 차로 번호 변경 오인이 없는지 점검한다.

## 보상 초안

- A1은 물리적으로 두 갈래 이상인 분기에서 예정된 다음 도로에 진입하면 +0.5를 1회 지급한다. 직선 도로의 단순 구간 경계는 제외한다.
- A2는 같은 통과 시점에 준비 가점을 최대 +0.25 추가한다. 채점은 분기 400m 전부터 시작하고, 진출 가능한 차로에 마지막으로 진입해 통과까지 유지한 거리를 d로 기록한다. 가점은 0.25 × min(d / 300m, 1). 진입 가능 구간이 300m 미만이면 분모를 지도에서 사전 산정한 실제 가용 거리로 줄인다. 이미 준비된 차량도 인정한다. 진출 가능 차로 사이의 이동은 유지로 처리한다. 원천적으로 선택할 필요가 없는 구간은 준비율 집계에서 분리한다. 목표 차로 판정은 보상과 로그에서만 사용한다.
- A3은 변경 명령 직전 센서로 관측한 목표 쪽 앞뒤 간격과 접근 속도로 위험을 계산한다. 측면 겹침 또는 접근 중인 차량과의 짧은 예상 충돌시간을 근거로 한 변경 시도에만 감점한다. 유지·단순 감속에는 부과하지 않는다. 연속 명령 한 번을 한 시도로 묶고 합법적으로 변경할 수 있는 곳에서만 채점한다. 첫 후보는 겹침 또는 2초 미만 접근시간에 시도당 최대 −0.1, 충돌 종료 스텝은 기존 −15만 적용한다. 임계값·스케일과 위험 노출당 지급 횟수를 점검 후 본 학습 전에 고정한다.
- 위 신규 계수는 실측 결과가 아닌 첫 비교용 제안값이다. 분기 대기 중 저속·막힘 벌점이 얼마나 발생하는지도 기록한다. 첫 비교에서는 이 벌점까지 동시에 변경하지 않는다.

## 학습·평가와 판단

- 비교 설정 제안은 모든 조건 동일한 PPO, 무교통 → 저교통 → 고교통 각 20만 스텝, 5만 스텝 간격 저장이다. 학습 seed 11로 1차 비교하고 유력 조건과 해당 대조군은 22·33으로 반복한다. 교통량·차종 구성·출발 차로·종료 한계도 동일하게 고정한다. 출발은 목적지와 독립적인 고정 차로 0을 사용한다.
- 중간 모델 선택은 별도 검증 seed에서 수행한다. 최종 주 비교는 고교통 15,000대/시간, 같은 16경로 × 교통 seed 3개 = 조건별 48회다. 최종 후보는 선택에 사용하지 않은 교통 seed에서도 별도로 검증한다. 단기 평가의 한두 건 차이로 우열을 확정하지 않는다.
- 주 지표는 완주·충돌·시간초과·기타 종료의 건수와 비율이다. 같은 경로·seed별로 기존 완주가 시간초과나 충돌로 바뀌었는지 대조한다. 분기 10m 이내에서 진출 불가능 차로로 시간초과한 횟수와 실제 다른 갈래 진입 횟수를 분리한다.
- 300m 확보율은 그 지점에서 준비 가능한 분기 접근만 분모로 사용한다. 300m 미만의 짧은 연속 분기는 별도 표로 보고한다. 초기 차로부터 이미 준비된 경우와 실제로 차로를 옮긴 경우를 구분한다.
- 합류 상호작용은 변경 전후의 상대 차량·간격, 가감속 명령·실제 속도 변화, 공간이 열린 시점, 변경 요청·실행을 함께 기록한다. 위험한 시도 비율, 정상 변경 횟수, 측면·전방·판별 불가 충돌을 구분한다.
- A2는 앞선 준비와 분기 실패 감소가 함께 나타나는지, A3는 충돌을 줄이면서 변경 포기·시간초과를 늘리지 않는지 본다. A4는 개선을 보인 항목을 조합할 때만 진행한다. 효과가 없으면 보상별 발생 횟수·누적량과 실패 직전 기록부터 확인한다.
