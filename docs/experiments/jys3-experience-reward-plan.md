# jys3 · 자기 주행 경험을 이용한 분기 보상 실험안

**질문**　처음부터 학습하는 같은 PPO에, 자신의 과거 주행으로 계산한 작은 중간 보상을 더하면 16개 경로의 완주가 늘고 오진출이 줄어드는가?

목적지까지 간 경험은 완주 보상으로 쓴다. 추가 보상의 학습 단위는 **한 번의 분기 접근**이다. 첫 분기를 맞히고 나중에 충돌한 주행도 첫 분기에 대해서는 성공 사례다. 갈래가 정해져 있어도 연결되는 차로는 여러 개일 수 있다. 어느 차로에서 언제 움직일지는 정책이 배운다.

> **담당자가 Codex에 전달할 요청**  
> 팀 저장소 jys3에서 아래 계획을 구현하고, 사전검증 → 자기 주행 데이터 수집 → 예측기 검증 → 같은 초기 가중치의 PPO A/B → 독립 평가 순으로 실행해 줘. 새 작업의 실제 커밋과 재현 명령을 기록하고 기존 결과 폴더와 구분해 줘. 검증을 통과하지 못한 예측기는 PPO 보상에 넣지 말고 실패 이유와 사례 수를 남겨 줘.

## 2. 두 비교군의 공통 설정

| 항목 | 설정 |
| --- | --- |
| 초기화 | actor·critic·학습 가능한 가속 표준편차를 새로 초기화. Adam 상태·버퍼·스텝 카운터도 새로 생성. seed별 0스텝 상태를 한 번 저장해 A/B 양쪽에 동일 복제하고 해시 검증. BC·DAgger·전문가 데이터·기존 PPO 가중치·참조 정책 KL·critic 사전 워밍업 없음 |

## 3. AV 자신의 경험으로 예측기 하나 만들기

1. **수집**. 파일럿 전용 seed 41·42·43으로 무작위 초기화한 PPO를 기본 보상 A에서 각각 65,536스텝 학습시키며 모든 전이를 기록한다. 초기 탐색부터 학습 도중 정책까지 포함한다. 본 실험 A/B는 파일럿과 별개의 새 가중치에서 시작한다. 보관 필드: 관측 50개, episode/접근 식별자, 학습·교통 seed, 경로, 출발 차로, 실제 외부 도로 전이, 분기 통과/이탈/충돌/정지/완주 사유. 관측 외 메타데이터는 묶기·검수용이다.
2. **라벨**. 400m 이내에 보이는 ‘다가오는 분기 하나’를 에피소드와 임무 경로상의 분기 인덱스로 추적한다. *결과가 일어나기 전*의 관측만 입력으로 저장한다. 해당 분기를 실제 맞게 통과하면 1, 다른 갈래로 실제 이탈하면 0이다. 분기까지 못 간 충돌·정지·시간초과는 미판정으로 기록하고 이진 학습에서 제외한다. 단순 합류나 분기와 무관한 이탈을 오진출로 세지 않는다. 짧은 내부 도로를 한 스텝에 건너뛰어도 실제 통과 기록으로 매칭한다.
3. **누출 방지**. 같은 교통 seed의 에피소드는 전부 같은 집합에 배정한다. seed 목록을 고정해서 학습/검증/예측기 시험을 70/15/15로 나눈다. 같은 분기 접근에서 거리대(0–100, 100–200, 200–300, 300–400m)별 관측은 하나씩만 고정 추출한다. 한 접근의 표본 가중치 합은 1로 두어 오래 멈춘 주행이 과대표집되지 않게 한다. PPO 선정·최종 평가의 교통 seed는 어떤 예측기 데이터에도 포함하지 않는다.
4. **학습**. 50→64→32→1 MLP, ReLU, 마지막 sigmoid에 해당하는 이진 분류(`BCEWithLogitsLoss`). Adam 0.001, batch 128, 최대 30 epochs, 검증 Brier score가 5회 개선되지 않으면 최저점 복구. 고정 seed 707로 한 번 학습해 모든 B에 같은 체크포인트를 쓴다. 점수는 **이 수집 정책들이 결과까지 간 사례에서의 통과 가능성 추정치**다.
5. **사용 여부**. 사전에 정한 최소 데이터 기준은 검증·시험 각각 성공/실패 30접근 이상이다. 별도 시험에서 학습 집합 평균 성공률만 내는 모델보다 Brier score가 낮고 ROC-AUC가 0.60 이상인지 확인한다. 11·13·16번과 거리대별로 표본 수, 예측확률 대비 실제 비율, 미판정률도 기록한다. 표본 부족이면 별도 파일럿 seed로 한 차례 추가 수집(동일 예산)한다. 기준 미달·경로별 심한 편향이면 B 본 학습을 보류한다. 결과가 나온 뒤 라벨을 차로 정답으로 바꾸지 않는다.

## 4. 성공 예측을 스텝 보상으로 연결

`Φ(obs)`는 분기 접근 중이면 고정 예측기의 확률(0~1), 그 밖이면 0이다. 접근 여부는 기존 `obs[35] >= 0`으로 정한다. 이미 종료된 상태의 Φ도 0이다.

```python
# pre_obs와 post_obs는 env.reset() 이전의 실제 연속 상태
phi_before = potential(pre_obs)
episode_end = terminated or truncated   # 위 time-limit-as-failure 설정
phi_after = 0.0 if episode_end else potential(post_obs)
shaping = beta * (gamma * phi_after - phi_before)
train_reward = base_reward + shaping
```

- `beta=0`(A) 또는 `0.2`(B), `gamma=0.99`는 PPO와 일치시킨다. 같은 상태에서 왼쪽·오른쪽 후보 행동을 가상 채점하지 않는다. 실제 움직인 뒤 상태가 어떻게 달라졌는지만 점수에 반영한다.
- 접근 **진입·이탈·종료를 포함한 모든 전이**에 같은 식을 적용한다. 음수도 보존한다. 접근 중에만 더하거나 양수만 남기면 경계를 왕복해 점수를 얻을 수 있다. 저장·재개 시 Φ 모델과 β도 복원한다. 예측기는 eval 모드로 고정하고 PPO의 gradient에서 분리한다.
- 이 항은 기존 성공·실패 정보를 시간상 나눠 전달한다. 예측기가 우연한 교통 패턴을 외웠거나 성공 사례가 부족하면 오히려 해로울 수 있다. **학습용 총점과 기본 보상·실제 완주·충돌은 별도로 집계**한다.

## 5. 담당 Codex의 실행 순서와 판정

아래는 **구현할 CLI 계약**이다. 저장소 루트에서 실행할 실제 명령·의존성·출력 경로를 구현 후 README 또는 결과 문서에 기록한다. 기존 모방 튜닝 실행기의 `main()`은 가중치를 로드하므로, 환경 팩터리와 50차원 래퍼만 재사용하고 PPO는 새로 생성한다.

```bash
python -m utils.jys3_experience_ppo preflight
python -m utils.jys3_experience_ppo collect --seeds 41 42 43
python -m utils.jys3_experience_ppo fit-potential
python -m utils.jys3_experience_ppo smoke --arms A B
python -m utils.jys3_experience_ppo train --arms A B --seeds 11 22 33
python -m utils.jys3_experience_ppo evaluate
python -m utils.jys3_experience_ppo report
```

1. **사전검증**. A에서 동일 seed·고정 행동으로 원래 −7 환경과 관측·기본 보상·종료가 일치해야 한다. 13/16번에서 같은 위치·차로의 경로만 바꾸면 기존 검사처럼 경로 지시가 달라져야 한다. 정상 통과, 실제 오진출, 분기 전 충돌을 각각 재생해 라벨 1/0/미판정을 확인한다. 예측 점수는 기존 50개 값만으로 재계산할 수 있어야 한다.
2. **스모크**. A/B를 각각 2,048스텝 수집하고 PPO 1회 업데이트한다. 0스텝 A/B의 정책·가치·optimizer 상태가 같고, β=0일 때 스텝마다 기존 보상과 같아야 한다. 합성 궤적에서 할인한 shaping 합이 `β(γ^T Φ_T − Φ_0)`와 일치하는지 검사한다. 종료·리셋을 가로질러 예측 점수나 GAE가 섞이면 수정한다.
3. **평가**. 16개 경로를 함께 학습한 정책 하나씩을 비교한다. 32,768스텝마다 고정 선정 패널 64회(경로당 4회), 끝에 독립 패널 256회(경로당 16회). 모든 조건이 같은 경로·교통 seed·출발 차로를 쓰고, 실제 출발 상태도 확인한다. 예시로 선정 base 91,510,000, 최종 base 92,510,000을 쓰고 각 패널에서 `seed=base+100*rep+경로번호`, `lane=min(rep%2, lanes-1)`. 먼저 전체 seed 목록이 파일럿·학습·이전 재사용 패널과 겹치지 않는지 검사한다. 선정 기준은 완주 수 → 적은 충돌 → 이른 체크포인트다. 선정 모델·마지막 모델을 모두 평가하고 최종 패널은 튜닝에 쓰지 않는다.
4. **주 지표**. seed별로 256회 중 완주·충돌·실제 오진출·정지·시간초과의 건수와 비율을 쓴다. 11·16번은 사례별 전후 전환, 13·16번은 출발 차로 0/1 × 경로 네 칸의 분기 성공/시작 수를 별도로 낸다. 분기 도달률과 도달 후 성공률을 함께 봐서, 분기 전에 멈춘 결과가 오진출 감소로 보이지 않게 한다.
5. **판정과 인계**. B의 완주율 상승과 실제 오진출률 하락이 3개 seed 중 적어도 2개에서 함께 나타나고, 전체 평균 충돌률이 증가하지 않을 때 후속 검증 후보로 둔다. seed별 안전성 악화와 짝지은 주행 결과를 공개하고, 작은 차이는 불확실로 남긴다. 초기 가중치·Φ 해시, 설정 및 seed 목록, 데이터 분포·검증 점수, 학습 스텝/시간, 체크포인트별 기본 성과, 실패 장면, 재현 명령을 전달한다. 파일럿 비용을 별도 표시하며 실제 학습·평가 전에는 개선 수치를 보고하지 않는다.
