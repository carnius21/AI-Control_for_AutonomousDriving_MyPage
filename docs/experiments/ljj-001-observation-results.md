# LJJ-001 · 위험 관측 묶음의 기준 대비 평가

기록일: **2026-11-16 (한국 시간)**. 사용자 노트북에서 완료한 `ljj-comparison.zip`을 집계했다. 새 학습·재평가는 실행하지 않았다.

**결론: 이 평가 표본에서 완주율 +8.33%p, 충돌률 −8.33%p. 시간초과는 그대로이며 일부 경로가 악화되어 main 기본값 채택은 보류한다.**

## 목적과 변경

- 목적: 위험 차량을 놓치거나 늦게 감속하는 문제에 관측 정보 보강이 도움이 되는지 비교.
- 기준: `--mode baseline`. 변경: `--mode observation`. 동일한 실행기의 관측 묶음만 다르며 도로/HV·보상·행동·PPO 하이퍼파라미터는 유지.
- 관측 변경: 기존 47차원의 빈 슬롯에 목표/준비 차로 안내 유효성 2개, 앞차 존재, 역TTC, 필요감속도, 앞차 종방향 겹침, 현재 차로 제한속도를 제공. 동일/좌우 인접 차로에서 관측 계산 시 음수gap을 버리지 않고 0m로 전달.
- 기존 전체 Route 기반 안내 유지, 안내 범위 300m·차량 관측 범위 50m 유지. 연결된 모든 램프 탐색·공통거리 투영·연속 횡방향 속도는 이 실험에 포함하지 않았다.

## 판정과 팀 공유

- **관측한 결과:** 해당 seed·예산·48개 평가사례에서 완주 증가와 충돌 감소를 확인했다.
- **일반화 판정:** 판단 보류. 학습 seed는 1개이며, 7개 특징+음수 gap 처리를 묶어 바꿔 개별 요소의 효과를 분리하지 못했다. 동일 교통 seed의 여러 경로도 모두 독립 표본이라고 가정하지 않는다.
- **목표 달성:** 미달. 변경 후 완주 33.33%, 충돌 12.50%, 전체 미완주 66.67%로 완주 ≥95%·미완주 ≤5%·충돌 <5%를 충족하지 못했다.
- **main 반영 의견:** 관측 묶음의 기본값 채택은 보류. `d9b00a9`의 선택형 observation 구현과 본 결과는 후속 비교 자료로 보존한다. 기준 모드·공통 도로·HV는 그대로 유지한다.
- **후속 검증:** 새 학습 전에 03의 충돌과 04·05·08·10·11·14의 시간초과를 대표 사례로 추적하여 원인을 분리한다. 이후 필요한 관측 부분 분리/다른 학습 seed 검증을 검토한다. 이번 작업에서는 추가 학습·보상/행동 변경·대량 수집을 실행하지 않았다.

### 최소 진단 조건

- 먼저 각 우선 경로의 평가 seed 9101 사례를 기준/관측 모델로 각각 재현하고, 필요하면 9102·9103으로 확장한다. 공통 시나리오·입력 해시·모델 해시·900초 warmup·AV 출발 조건을 유지한다.
- 기록 항목은 시각, Route index, edge/lane/위치/속도, 현재·준비 목표 차로 및 거리, 앞차 ID/속도/gap, 인접 차량, 원시 관측·행동, 요청/수락/거절 사유, 실제 이동과 충돌 상대·유형이다. 차로 번호가 edge 경계에서 바뀐 것과 같은 edge 내 실제 차로 변경을 구분한다.
- 진단 구간의 상세 추적과 시간초과 전 마지막 구간을 보존한다. 긴 대기 시간을 줄인 별도 진단을 하더라도 그 결과를 기존 10,800초 한도의 공식 평가 수치에 섞지 않는다.
- 현재 ZIP에는 이 추적 정보가 없으므로 추가 기록·재생 기능이 필요하다. 이번 문서 추가만으로 진단을 수행한 것은 아니다.

### 진단 후 결정할 실험

1. 관측 누락·정규화·gap 의미를 확인하고, 필요하면 위험 관측/안내 유효성/음수 gap 처리를 분리 비교한다. 시간초과 경험의 GAE 경계 처리도 후속 학습 전 정확성을 점검한다.
2. 행동 안전 게이트와 보상 변경은 각각 별도 비교한다. 게이트의 규칙 기반 차단 효과와 정책 자체의 학습 개선을 구분한다. 이번 관측 실험 결과만으로 두 후보의 우열을 결정하지 않는다.
3. 유망한 변경은 다른 학습 seed 및 별도 평가 사례에서 확인한다. 그 후에 main 채택과 대량 수집을 검토한다. 평가 시간 증가도 함께 보고해 성능과 실행 비용을 비교한다.
