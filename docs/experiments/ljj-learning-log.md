# LJJ 학습 실험 기록

`ljj_aftermid`에서 진행한 실험의 목적·조건·결과를 남기고, 팀 `main`에 반영할 변경을 고르는 기록장입니다. 학습 종료 후 아래 비교표와 실험별 기록을 함께 갱신합니다. 실패·중단한 실험도 남깁니다.

## 실험 비교표

완주율·충돌률은 **동일한 평가 조건에서 기준 → 변경 후** 순서로 적습니다. 완주율 차이는 `%p`로 표시합니다.

| 실험 ID·주제 | 목적·변경 요약 | 완주율: 기준 → 변경 (차이) | 충돌률: 기준 → 변경 | 개선 판정 | main 반영 의견 |
|---|---|---|---|---|---|
| [LJJ-001 · 위험 관측 묶음](ljj-001-observation-results.md) | 앞차 위험·안내 유효성·제한속도 추가 및 음수 gap 관측 유지 | 25.00% → 33.33% (+8.33%p) | 20.83% → 12.50% | 표본 내 개선 확인 / 일반화 보류 | 보류: 일부 경로 악화·목표 미달 |

실험마다 다음 ID를 추가하고 아래 상세 기록 및 결과 문서와 연결합니다.

## 기록·판정 기준

- 가능하면 한 실험에서 한 요소만 바꾸고 기준 조건도 평가합니다. 평가 맵·경로·교통·출발 조건·seed가 다르면, 공통 평가를 하기 전까지 개선 판정을 보류합니다.
- **개선 확인**: 비교 가능한 평가에서 완주율이 높아지고 충돌률이 악화되지 않음. **개선 없음**: 개선 미확인. **상충**: 완주율·충돌률 등의 결과가 엇갈림. **판단 보류**: 평가 미완료·반복 부족·조건 불일치. **오류·중단**: 학습/평가 미완료.
- 학습 seed별 결과와 편차를 확인해 `채택 후보 / 보류 / 제외` 의견을 적습니다. 일부 사례·한 seed의 개선만으로 전체 성능 개선을 확정하지 않습니다. 실제 main 반영은 팀 검토 후 PR로 진행합니다.
- 충돌률이 낮아도 완주하지 못하면 성공으로 판단하지 않습니다. 최종 목표인 [충돌률 5% 미만·목적지 완주·충분한 HV 상호작용](../../project_materials/6_Project_Evaluation.md)은 별도로 확인합니다. 무교통 검증 결과는 HV가 있는 평가와 구분합니다.
- GitHub에는 코드·설정·요약을, 모델·TensorBoard·원시 결과는 로컬 `results/`에 보관합니다. 아래에 원본 위치와 설정/맵/모델 해시를 담은 manifest 경로를 남깁니다. [데이터 보관 정책](../../data/README.md)을 따릅니다.

## 실험별 기록 양식

아래 양식을 복사해 이 문서 끝에 실험별로 추가합니다. 미실행 항목은 `미실행`, 확인하지 못한 값은 `미확인`으로 남깁니다. 긴 설정은 스냅샷·manifest를 참조하고 핵심 변경만 본문에 적습니다.

```markdown
## LJJ-001 · 실험 주제

- 일자: YYYY-MM-DD (한국 시간)
- 목적: 무엇을 바꿔 어떤 주행 문제/완주율을 개선하려 했는지 한 문장.
- 비교 기준: 기준 실험 ID 또는 기준 run 경로.
- 변경: 파일·설정명, 변경 전 → 후. 여러 요소를 바꿨다면 모두 명시.
- 코드: 출발한 main 커밋 / 기준 실행 커밋 / 변경 후 실행 커밋.

### 학습·평가 조건

| 항목 | 기록 |
|---|---|
| 환경 | 맵 파일·SHA256, 환경 생성 함수, 관측 버전·차원, 행동·안전 게이트 설정 |
| 교통·출발 | HV 수요·차종/성향 비율, warmup, AV 출발 조건, 시간 제한. 기준과 다른 값 명시 |
| 학습 | 알고리즘, 실제 학습 스텝, 학습 seed, 주요 변경값 및 전체 설정 스냅샷 경로 |
| 초기화 | 처음부터 / 이어 학습. 이어 학습이면 원본 모델·누적 스텝·optimizer 복원/초기화 여부 |
| 평가 | 대상 경로·사례 수·평가 seed 목록 또는 조건 파일, 결정적/확률적 행동 선택 |
| 평가 모델 | 최종/중간 체크포인트와 실제 스텝. 중간 모델 선택에 쓴 검증과 최종 시험 구분 |

### 평가 결과

학습 seed별로 기준/변경 행을 추가합니다. 각 지표는 `건수/N (비율%)`로 적습니다.
N은 정상 시작한 평가 에피소드 수입니다. 삽입 불가·실행 오류는 별도 집계하고, 예정 사례를 다 평가하지 못하면 미완료로 표시합니다. 완주·충돌·시간초과·기타 종료를 중복 집계하지 않습니다.

| 조건 | 학습 seed | 평가 N | 완주 | 충돌 | 시간초과 | 기타 종료 |
|---|---|---|---|---|---|---|
| 기준 | 미기록 | 미기록 | 미기록 | 미기록 | 미기록 | 미기록 |
| 변경 | 미기록 | 미기록 | 미기록 | 미기록 | 미기록 | 미기록 |

- 평가 완료 여부 / 삽입 불가·실행 오류: 예정 대비 완료 수와 원인.
- 완주율 변화: 변경 후 − 기준 = 미기록 %p. 반복 결과는 seed별 변화와 평균을 함께 기록.
- 개선 판정: 개선 확인 / 개선 없음 / 상충 / 판단 보류 / 오류·중단.
- 주요 관찰: 실패 경로·위치, 감속/합류/차로 선택 등 확인한 행동과 아직 확인하지 못한 원인.
- main 반영 의견: 채택 후보 / 보류 / 제외 — 이유 한 문장, 반영할 코드 커밋·파일.
- 원본 근거: 기준/변경 run 경로, 평가 결과 파일, 설정·맵·모델 SHA256을 담은 manifest 경로.
- 후속: 다음에 확인할 것 한 문장 또는 없음.
```

## LJJ-001 · 위험 관측 묶음 비교 (2026-11-16)

- **목적:** 앞차 위험과 겹친 차량을 더 정확하게 관측하면 완주·충돌 성능이 개선되는지 확인.
- **기준/변경:** 같은 시나리오·PPO·보상·행동에서 `baseline`과 `observation` 비교. [상세 조건·경로별 결과·해시](ljj-001-observation-results.md).
- **코드:** 개인 브랜치 기준 `5cb44c1`에 실행기를 추가한 `d9b00a9179f944770d2fd02f9da73ac905c8f513`로 두 조건 실행.
- **학습:** 처음부터 PPO, 학습 seed 0, 각 100,352스텝. **평가:** 최종 모델, 16경로 × 평가 seed 9101/9102/9103 = 조건당 48회.

| 조건 | 완주 | 충돌 | 시간초과 | 기타 종료·삽입실패 |
|---|---:|---:|---:|---:|
| 기준 | 12/48 (25.00%) | 10/48 (20.83%) | 26/48 (54.17%) | 0 |
| 관측 변경 | 16/48 (33.33%) | 6/48 (12.50%) | 26/48 (54.17%) | 0 |

- **개선 여부:** 이번 표본에서 완주 +8.33%p, 충돌 −8.33%p. 동일 사례 중 실패→성공 12건, 성공→실패 8건으로 순증 4건. 일반화는 판단 보류.
- **목표 달성:** 미달. 완주 ≥95%·전체 미완주 ≤5%·충돌 <5%를 충족하지 못함.
- **경로 차이:** 01·12·15는 0→3회 완주. 반면 03은 3회 완주→3회 충돌, 04·05는 각각 2→0회 완주.
- **main 반영 의견:** 기본값 채택 보류. 선택형 관측 구현과 이 비교 결과를 공유하고, 악화·시간초과 원인 추적 후 재검토.
- **시간:** 기준 학습 91.24분 / 평가 4.04시간, 관측 학습 88.40분 / 평가 7.04시간. 두 조건 모두 시간초과 26건이 시뮬레이션 주행 한도 10,800초에 도달함.
