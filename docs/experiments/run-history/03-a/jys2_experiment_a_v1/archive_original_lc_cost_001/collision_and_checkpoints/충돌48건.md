# 실험 A 충돌 48건 재현 기록

고교통, 학습 seed 11, 60만 스텝 최종 모델. 모든 재현은 기존 충돌과 경로·평가 seed·종료 유형이 일치했다. 아래 값은 충돌을 일으킨 0.2초 스텝의 직전 관측과 해당 스텝에 낸 명령이다. 원본 파일은 충돌 이전 최대 5초를 담는다.

앞 간격과 상대속도는 정책의 현재 차로 앞차 입력을 역정규화했다. 간격은 SUMO 기반 입력으로 범퍼 실측 거리와 다를 수 있다. Δv는 앞차 속도 − AV 속도(m/s)다. 가감속은 정책 원본 명령(−1~+1). 실감속은 그 직전 0.2초 두 속도 표본의 차이가 −0.01m/s 미만인 경우다. 마지막 프레임의 차선변경 명령 접수는 충돌 스텝의 이동 성공과 구분한다.

전방은 AV가 SUMO 충돌 유발 차량이며, 상대가 직전 선행 차량이고 같은 차로 또는 진행 연결로에 있었던 경우다. junction 중 동일 내부 차로에서 선행 차량을 추돌한 A3·41211도 전방으로 분류했다. 다른 내부 경로가 만나는 junction은 합류, 명시적 side는 측면으로 분류했다. 위험 시도는 유효한 목표 차로로 새 변경 시도를 냈을 때만 목표 차로의 겹침 또는 2초 미만 접근시간을 센다.
