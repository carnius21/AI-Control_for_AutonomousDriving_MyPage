# 실험 B 실행 기록

## 소스와 실제 정책 입력

팀 저장소 jys2의 HEAD는 e5391a9b1894edc6b8934f338811a8b5f8150ece, 보상 참조 원본 origin/mcw2는 d81e0b03165572038eac7bc6433b0ec755565b4f다. jys2 작업 폴더의 실험 A 보조 파일 utils/experiment_a.py에 있는 RoadEnv와 분기 통과 보상을 재사용했다. 해당 파일은 jys2 커밋에 포함되지 않아 design.json에 사용 파일 해시를 남겼다.

38개 정책 입력은 속도 1개, 주변 5개 차로의 앞뒤 상대 거리·속도 20개, 물리적 차로 연결 5개, 밀도 5개, 현재 차로·제한속도·램프 여부·도로 단위 분기 방향·분기 거리·좌우 겹침 7개다. 두 팔 모두 route_conn을 끄고 RoadEnv가 직접 만든 입력을 사용한다. 실제 노출 입력에는 목표 차로, 준비 마스크 및 경로 연결 차로 피처가 없다. 13·16번을 분기 80m 전 동일 위치·차로에서 비교한 원시 입력은 input_check_B0.json과 input_check_B1.json에 담았다.

행동은 연속 가감속과 세 범주의 차로 명령이다. 안전게이트와 SUMO 자율 속도·차로변경 모드는 꺼져 있다. 실선, 존재하지 않는 차로, 교차로 내부에서의 차로변경은 기존 지도의 물리적 제약을 따른다. 일반 차로변경·위험 시도 추가·무효 명령 벌점은 0이며 실제 충돌 보상은 −15다. 공통 종방향 TTC·정체·속도·완주·시간초과 설정은 jys2를 따른다.

## 보상 지급 확인

B0는 올바른 다음 도로에 도달했을 때만 지급한다. 확보 후 유지한 거리 / min(300m, 접근 가능 거리)를 1로 제한해 0.25를 곱한다. 중간에 이탈하면 확보 거리를 다시 계산한다.

B1의 원본은 origin/mcw2:utils/mcw_train.py의 McwEnv.step 및 utils/train_lane_learning.py의 ProgressReward.award다. 지도 연결을 역추적해 400m 이내의 준비 대상 차로를 구하고 같은 일반 도로 안에서 실제 차로가 변해 가장 가까운 목표까지의 차로 수가 줄어들면 줄어든 수준당 3 × 0.1을 지급한다. 에피소드마다 (현재 도로 ID, 정렬된 목표 차로 집합, 획득한 거리 수준)을 기억한다. 같은 수준을 다시 달성해도 추가 지급하지 않는다. 주석에 적힌 300~400m와 달리 실제 활성 범위에는 300m 이내도 포함된다.

별도 고정 행동 시험에서 13번 차량을 분기 70m 전 1차로에 놓고 1→0→1→0차로로 이동시켰다. B0는 출구 37927508에 진입한 스텝에서만 +0.04444, B1은 첫 1→0 변경에서만 +0.3을 받았다. reward_probe.json에 각 명령과 실제 차로를 기록했다.

## 편성과 해석

첫 스텝부터 고교통에서만 학습한다. 원본 시나리오는 scenarios/hv_high15000_entryprep이며 생성한 실행 파일과 세 수요는 design.json에 기록했다. 학습은 에피소드 16개마다 시드로 고정한 경로 순열을 한 바퀴 돌고 다음 순열로 넘어간다. 차로는 블록마다 0·1을 교대하며 단일 차로에서는 0을 사용한다. SUMO에 위치 0, 속도 max를 요청하고 실제 출발 위치·속도·차로·SUMO 시드를 episodes.jsonl에 쓴다. 고정 스텝 예산이므로 정책별 에피소드 길이에 따라 마지막 블록의 길이와 총 에피소드 수는 다를 수 있다.

중간 평가에는 두 출발 차로에 각각 810000·810001을 배정한다. 최종 검증은 910000·910001 및 910100·910101이다. 경로별로 같은 교통 수준과 출발 차로의 평가 시드를 공유한다. 평가에는 각 32회, 미사용 시드 검증에는 각 64회 주행을 배정했다. 경로 쌍의 양쪽 실제 출발 도로·차로·위치·속도·삽입 시각이 모두 일치해야 집계한다. 13·16번에서 0차로는 진출 적합·본선 변경 필요, 1차로는 본선 적합·진출 변경 필요다. 겹치는 차로에서 출발해 두 경로를 모두 통과할 수 있는 다른 분기와 구분해 해석한다.

report.md, checkpoint_metrics.csv, route_metrics.csv, pair_cases.csv, failure_scenes.csv 및 최종 holdout_metrics.csv를 사용한다. 300m·100m 수치는 문턱을 처음 통과한 실제 시뮬레이션 스텝이다. 거리 단위는 m, 속도 단위는 m/s, 가감속 출력은 정규화된 명령이다. 간격 null은 시야 안에서 상대 차량 미검출이다.
