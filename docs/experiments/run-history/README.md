### 자료 범위
원래 결과 파일명과 실험 폴더명을 유지했다. checkpoint-outcomes.csv는 파일별 종료 사유 집계다. diagnostic-cases.csv는 기존 진단에서 주행별 단일 값들을 추출했다. 평가 실패나 중단 기록도 보존했다. 별도 요약이 없던 자료는 해당 폴더에 보관 형태를 적었다. 대형 모델 가중치, 시뮬레이션 복제본, 매 스텝 원시 궤적은 로컬 results에 보관한다.

코드 이력은 실험 당시 남은 커밋·해시와 이번에 보관한 파일을 구분한다. 기존 원격 이력은 [초기 PPO](https://github.com/jy02sung/Artificial-Intelligence-and-Control-for-Autonomous-Driving/tree/codex/ic-ppo-experiments), [교통 단계](https://github.com/jy02sung/Artificial-Intelligence-and-Control-for-Autonomous-Driving/tree/codex/ic-traffic-stages), [이전 관측·보상 실험](https://github.com/jy02sung/Artificial-Intelligence-and-Control-for-Autonomous-Driving/tree/codex/av-observation-reward-20261114/docs/experiments)에 있다. jys2에서 미추적이었던 실행 코드는 현재 보존본으로 단계별 커밋했다. 과거 버전은 기록된 해시 또는 당시 사본이 있을 때 확인할 수 있다.
