# 퇴계원·사노IC 맵 전체 형상 점검 (2026-11-07)

## 범위와 결과

- 통행 가능한 접속부 **68곳**, 외부 도로 **90개**, 외부 차로 **202개**를 검사했다.
- 모든 접속부의 외곽과 실제 차로 중심선·내부 연결선을 8개 도면으로 펼쳐 점검했다. 사용자 지적 분기부는 SUMO 확대 화면에서도 다시 확인했다.
- 분기부 **6곳**의 12개 출구 도로 중심을 실제로 물려받는 차로 묶음의 위치에 맞췄다. 3→1+2 등에서 두 출구를 같은 중앙점에 붙여 차로가 갑자기 옆으로 꺾이던 문제를 수정했다.
- 동일 차로 수의 일반 연결부 **23곳**은 전후 진행 방향을 맞췄다. 남쪽 램프 3763690380의 약 8cm 내부 연결선 역방향 꺾임도 수정됐다.
- 전후 외부 차로 수와 차로별 출발·도착 연결 관계를 비교했다. 도로 경로를 쉽게 만들기 위한 변경이 아니라 형상 정렬이다.
- 북쪽 차로 감소 위치는 다음 합류 **50m 전**, 북쪽 합류 후 **5차로**, 지도 경계 축소를 유지한다.

## 검증 근거

`maps/toegyewon_osm/geometry-review.json`에 맵 SHA256, 접속부별 입력·출력 도로와 차로 연결부 방향 차이를 기록한다. 외부 차로 선분의 최대 방향 변화 및 내부 연결선의 입·출구 접선 차이가 10도를 넘으면 검사가 실패한다. 이 기준은 이번 맵의 급격한 꺾임 재발을 찾는 검사이며 도로 설계 기준을 의미하지 않는다.

`python -m utils.audit_osm_geometry`로 68곳의 검사와 도면을 재생성할 수 있다. 도면은 `maps/toegyewon_osm/geometry-review/`에 저장된다. `layout-adjustments.json`의 `whole_map_alignment_review`에 수정한 지점을 기록했다.

차로 연결 끝점 간 5cm 초과 공백은 없었다. 현재 외부 차로 선분의 최대 방향 변화는 약 5.83도, 연결부 입·출구의 최대 접선 차이는 약 5.93도다.

무교통 기본 SUMO 운전자 시험은 기존 23건과 외부 연결별 출발 차로·도착 도로 조합 195건을 합쳐 **218건**으로 확장했다. 모두 도착했고 충돌·텔레포트가 없었다. 여러 도착 차로로 갈 수 있는 연결에서는 실제 도착 차로를 강제로 지정한 시험은 아니며, 차로별 연결 자체는 정적 검사·도면으로 별도 확인한다.

아주 짧은 도로에 5m/s로 차량을 직접 넣으면 출발 자체가 거부되는 사례가 있어, 연결별 시험은 정지 출발로 통일했다. 대표 경로 23건의 조건은 유지했다.

## 범위의 한계

이번 결과는 맵의 기하 형상과 통과 가능성 확인이다. 위성사진 대비 모든 차로 수·실선·점선의 현장 정확성, 혼잡 시 교통 용량, AV 학습 성능을 입증하지 않는다. 기존 미확인 표식과 OSM 기본 차로 정보는 import-audit.json에 그대로 표시한다. 학습·데이터 수집은 재개하지 않았다.

## 서쪽 3차로 분기 위치 추가 수정

사용자 확인에 따라 1808903388 분기점을 진행 방향으로 약 44m 이동했다. 기존 위치에서 바로 1+2차로로 분리하던 구성을 바꿔 169929488#0의 3차로를 실제 갈라지는 구간까지 연장했다. 주행 방향 오른쪽 차로(0)는 169728799로, 나머지 두 차로는 169929488#1로 이어진다. 세 도로의 곡선과 접선을 함께 조정했으며 전체 연결 관계와 차로 수는 보존했다. 위치는 사용자 화면에 맞춘 모델링 보정으로 실측 좌표는 아니다.

SUMO 확대 화면 확인, 전체 기하 검사와 정적 차로 연결 검사를 수행했다. 분기 좌표와 접근 3차로에 회귀 검사를 추가했다. 무교통 기본 운전자 218건도 전부 도착했으며 충돌·텔레포트가 없었다. 학습과 데이터 수집은 중단 상태를 유지한다.

## 남향 본선 5→4차로 감소 지연

북쪽 진입 86198728에서 램프가 갈라지자마자 4차로가 되던 위치를, 다음86198725의 시작 기준50m 지점으로 옮겼다. 생성된 실제 차로 기준 추가5차로 구간은 약41.8m이며 차이는 교차부 내부 연결 길이 때문이다. 위치는 사용자 요청에 따른 모델링 조정이며 현장 실측값은 아니다. 기존4개 차로는 직진 축을 유지하고 우측 보조차로만 종료된다. 유지 차로 축의 횡방향 오차는 약1.1cm 이내다. 보조차로와 옆 차로 경계는 변경을 허용하고 나머지 기존 실선 제약은 유지한다.

전체맵과 퇴계원 전용맵에 반영했으며, 정적·기하 검사 및 기본SUMO 운전자223/223 통과(충돌·텔레포트0)를 확인했다. 경로는 여전히16개다. 기존AV 평가결과는 이전맵의 결과로 보존하며 이번맵에서 재평가한 결과가 아니다. 과거결과를 새맵의 완료 결과로 재사용하지 못하도록 해시 검사도 추가했다. 이 지점은 ④·⑭의 공통 실패구간170059994/1063527748과 다르므로 그 실패 해결로 주장하지 않는다.

## 감소부 도로 외곽 돌출 제거

사용자가 표시한 검은 돌출부의 SUMO 객체는 `junction:86198725.50`이었다. 차로 감소 때 자동 생성된 둥근 외곽이 바깥 차로 종료 공간을 메우고 있었다. 접속부 외곽을 유지되는4차로의 경계에 맞춘 사각형으로 제한했다. 모든 외부·내부 차로의 형상 및 속성은 이전 커밋과 동일함을 비교 검증했다. 램프를 이동하거나 화면에 배경색 도형을 덧씌운 변경이 아니다. 확대 SUMO 화면에서 빈 공간을 확인했다.


## 감소부 외곽 과절삭 수정 (앞 절의 수정 재보정)

직전 외곽 수정은 유지되는 4개 차로 경계만 남겨, 종료되는 바깥 차로의 입구 포장면까지 잘라낸 오류가 있었다. 사용자 화면에서 차로가 갑자기 사라져 보인 원인이다. 이번에는 5차로 입구의 양 끝과 4차로 출구의 양 끝을 모두 보존한 사다리꼴로 접속부를 연결했다. 둥근 돌출부 대신 직선으로 좁아지며, 입구 차로를 잘라내지 않는다.

모든 외부·내부 차로의 형상과 속성은 직전 커밋과 동일함을 비교했다. 유지되는 네 차로의 축은 그대로이며, 50m는 감소 위치까지의 거리이고 실제 접속부 테이퍼 길이는 약 8m다. 테이퍼를 50m로 늘린 것으로 해석하지 않는다. 입·출구 가장자리 네 점이 실제 차로 폭과 일치하는지 확인하는 회귀 검사를 추가했다.

정적 차로 연결 검사와 기하 검사 통과, 무교통 기본 SUMO 운전자 223/223 도착, 충돌·텔레포트 0을 확인했다. 전체맵과 퇴계원 전용맵을 함께 갱신하고 SUMO에서 다시 불러와 확인했다. 이는 기하 수정 검증이며 AV 성능 개선 검증은 아니다.

## 최종 사용자 수정: 일반적인 5 → 본선 4 + 램프 1 분기

위 두 차례의 외곽 수정은 원인을 해결하지 못했다. 사용자가 참고 화면처럼 단순 분기시키도록 요청하여, 램프 분기 이후 5차로를 연장했다가 별도로 줄이던 구조를 제거했다. 이 요청은 앞선 50m 연장/감소 설정을 대체한다.

- `86198728`의 바깥 0번 차로는 `37927508` 램프로만 연결한다.
- 나머지 1~4번 차로는 `86198725` 본선 0~3번 차로로 연결한다.
- `86198725#1` 및 별도 감소 접속부 `86198725.50`을 없앴다. 외곽을 자르는 후처리도 제거했다.
- 전체맵과 퇴계원 전용맵 및 경로 파일을 재생성했다. 진입~진출 경로 수는 16개를 유지한다.

정적 검사에서 분기 연결 집합이 정확히 4+1인지 확인하고 별도 감소 접속부가 없는지 검사한다. 전체 기하 검사 통과, 기본 SUMO 운전자 218/218 도착(충돌·텔레포트 0). 직전 223건과의 차이는 불필요한 5차로 감소 연결 제거로 검사 대상이 줄었기 때문이다. AV 재학습/재평가 결과는 아니다. SUMO에서 수정 파일을 다시 불러와 중간 돌출부가 없어진 것을 확인했다.
